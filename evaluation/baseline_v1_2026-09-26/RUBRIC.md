# 回答基线评分口径 v1

- correct：回答主要问题，必要适用条件完整，无影响结论的无依据事实或个人推断。
- partial：主方向正确，但遗漏必要条件/可回答事实，或附加无依据规则、未经确定的边界判断。
- incorrect：关键答案与手册冲突，包括明文及组合条款可回答却错误拒答。
- 引用评分独立：事实正确但错引范围或子条号，不自动把回答判错；事实内容的错误归属仍记录。
- 严格正确率 = correct / 36；partial 不计为正确，不命名为可用率。
- 完全引用支持回答比例：所有去重事实复核项均为supported的回答数/36；是此轮模型审查口径。
- 复核项允许合并档位/材料清单，不能称严格原子断言准确率或逐引用精确率。
- 缺个人条件的题允许给有条件的规则并索取缺失信息，不能推算个人结果；未明文时间地点边界转负责人核实。
- 显式可能性假设和建议不自动作为确定政策。例如N02个案时长可能不同不改变主答案正确性，但引用缺依据仍独立扣分；N11/N15使用通常陈述制度权责或预算关系，按无依据附加事实计部分正确。
- 未检索到和手册全文没有分开；对输入片段未知的说明可成立，最终完整回答仍须核对全册已给的答案。
- U1：四类离职分别说明，辞职通知期不自动套用到协商解除或依法终止。
- U2：公司发起/员工发起调动分别说明；不自行决定书面同意与人才开放原则的优先关系。
- U3：未定义的时间地点边界不推断，建议向具体负责部门确认。
- 这版题目、原输出和评分口径固定后用于同设置对照；后续修正标签应创建新版并同时重评两轮。
- 本36题已用于分析问题，属于开发/回归集；优化后在同集上的提升需另建未用于调参的保留题集验证泛化。
