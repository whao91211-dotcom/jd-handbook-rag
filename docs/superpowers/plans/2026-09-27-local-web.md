# Local Web Implementation Plan

> Execution: superpowers:executing-plans, inline as explicitly requested by user.

**Goal:** Run the existing RAG through a local evidence-first web UI.
**Architecture:** Same-origin static assets and FastAPI; lazy RAG imports, serialized pipeline, per-request usage.
**Tech Stack:** Python, FastAPI, Uvicorn, HTML/CSS/JavaScript.
**Spec:** docs/superpowers/specs/2026-09-27-local-web-design.md

## Constraints and review focus
No API secrets in browser, no fake metrics, no model HTML execution. Preserve baseline. Original-query evidence and actual context maps must match. Failures retain evidence; concurrent calls receive busy state. Localhost only.
