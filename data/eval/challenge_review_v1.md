# 拟真问法与困难负样本：候选集 v1

数据文件：`challenge_candidates_v1.jsonl`。本批 16 题由项目复盘时模拟员工表达编写，**不是实际员工日志**，也不是已人工复核的正式 golden set。所有题均标记 `needs_human_review`；现阶段不并入 `golden.jsonl`，不更新 README 中的既有检索成绩。

## 构成

- C-P01～C-P08：8 条口语化正样本。保留原 golden 题的知识点，但改变说法；C-P06 额外要求跨三个块核对事假、无薪假及餐补规则。
- C-N01～C-N08：8 条困难负样本。每题都附有手册中相近的条款，但问题所需的关键细节未在附带条款中给出。人工复核时还需通读整册，确认其他位置也没有答案。
- `gold_chunk_ids`：正样本的候选充分证据集合。`related_chunk_ids`：负样本的相近证据，**不是**其答案。`required_points` / `expected_behavior` 是人工判定提示，并非自动评分器。

## 人工复核后才能进入正式评测

1. 对正样本核实提问是否自然、是否存在歧义，以及 `gold_chunk_ids` 是否覆盖全部必要证据；必要时补充其他块。
2. 对困难负样本逐条核对整册语料，确认 `missing_detail` 确实不存在；若有答案，将该题转为正样本并标出证据。
3. 固定题目与标注后，分别报告检索命中、回答正确性、拒答或澄清是否恰当，以及**每个事实断言是否被对应引用支持**。
4. 如果取得经授权、去标识化的真实用户问题，单独标注来源并建立独立测试切片；不要把本批拟真问题改称真实用户问题。
